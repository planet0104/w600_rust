# music_box：TW-01 音乐盒

为 TW-01（W600，8 针、兼容 ESP-01 封装）设计的示例：

- **按钮即电源开关**：两个按钮都能给板子上电，按住才通电，松开即断电；
- **按哪个按钮决定舵机方向**：按住按钮 1 开机舵机逆时针转，按住按钮 2 开机顺时针转，转速为全速的 50%；
- **同时播放儿歌**：蜂鸣器循环播放《新年好》《两只老虎》《生日快乐》《小小世界》《伦敦桥》；
- **断电续播**：每次开机从上次播放那首的**下一首**开始，播放记录保存在 Flash 中。

舵机需要改装成可以连续旋转（见下文），改装后可以控制方向和转速。

## 运行

```powershell
cd examples
cargo run --release --bin music_box -- --monitor --port COM5 --reset none
```

TW-01 的 TX0 在这个示例里用来驱动舵机，所以要把 TW-01 插到下载器上烧录（下载器供电时两个按钮都没按下，舵机不会启动，
串口日志可以正常查看），烧好后再插回音乐盒的电路板。TW-01 下载器通常没有自动复位，用 `--reset none`，
在出现 `wait serial sync...` 后拔插一下模块或把 RST 短接一下 GND。

下载器上运行时串口会打印：

```
music box: direction Stop, start from song 2
playing: Happy Birthday
```

每次重新上电，`start from song` 应该加 1（5 首之后回到 0），说明断电续播正常。

## 所需材料

| 材料 | 说明 |
| --- | --- |
| TW-01 模组 | W600 |
| 5V 锂电池充放电板 | 输出 5V，建议 1A 以上（舵机堵转约 0.7A，W600 射频峰值约 0.3A） |
| 9g 舵机（SG90 等） | 按下文改装成连续旋转 |
| 无源蜂鸣器（模块） | 带三极管的模块更响 |
| 2 个按钮 | 自锁或点动均可，按住期间通电 |
| 2 个肖特基二极管 | 1N5819 或 SS14，**不要用 1N4007**（压降约 1V，稳压器输入电压会不够） |
| 3.3V 稳压器 | AMS1117-3.3 或现成的 5V 转 3.3V 模块（输出能力 500mA 以上） |
| 电阻 | 10kΩ × 4，15kΩ × 2 |
| 电容 | 470µF（舵机电源）、100µF（TW-01 电源），以及稳压器要求的输入输出电容（AMS1117 为各 10µF） |

## 接线

### 电源与按钮

```
                    ┌── 按钮 S1 ──┬── D1 (1N5819) ──┐
                    │             │                 │
5V 电池板 OUT+ ─────┤           10kΩ                ├──── VS（约 4.7V）
                    │             ├──── PB11 (RX1)  │
                    │           15kΩ                │
                    │             │                 │
                    │            GND                │
                    │                               │
                    └── 按钮 S2 ──┬── D2 (1N5819) ──┘
                                  │
                                10kΩ
                                  ├──── PB12 (TX1)
                                15kΩ
                                  │
                                 GND

VS ──┬── 舵机红线 (+)
     ├── 470µF ── GND
     └── 3.3V 稳压器输入 ── 稳压器输出 ──┬── TW-01 3V3
                                          ├── 100µF ── GND
                                          └── 10kΩ ── TW-01 RST
```

- 按下 S1 或 S2，5V 经二极管送到 VS，给舵机和稳压器供电，整个电路开机；松开按钮即断电。
- 两个二极管防止按下一个按钮时电流倒灌到另一个按钮的检测线，否则两条检测线都会读到高电平。
- 检测线从按钮与二极管之间引出，经 10kΩ + 15kΩ 分压后接到 IO：5V × 15 / (10 + 15) = 3.0V，
  低于 W600 IO 的上限 3.6V。15kΩ 同时充当下拉电阻（W600 的 GPIO 没有内部下拉），按钮没按下时读到低电平。
- 舵机直接用 VS 供电，不要接在 3.3V 上；电池板、稳压器、TW-01、舵机、蜂鸣器的 GND 全部连在一起。
- RST 接 10kΩ 上拉到 3V3，避免干扰导致误复位。

### TW-01 引脚分配

| TW-01 引脚 | W600 引脚 | 连接 |
| --- | --- | --- |
| 3V3 | — | 稳压器 3.3V 输出 |
| GND | — | 公共地 |
| RST | — | 10kΩ 上拉到 3V3 |
| PA1 | PA1（PWM 通道 1） | 蜂鸣器信号（I/O），另接 10kΩ 下拉到 GND |
| TX0 | PA4 | 舵机信号线（橙色或黄色） |
| RX1 | PB11 | 按钮 S1 的检测线（分压后） |
| TX1 | PB12 | 按钮 S2 的检测线（分压后） |
| RX0 | PA5 | 不接（留给烧录） |

蜂鸣器模块的 VCC 接 3.3V、GND 接地、I/O 接 PA1，**并在 PA1 和 GND 之间接一个 10kΩ 下拉电阻**：
W600 复位后所有引脚都是没有上下拉的高阻输入，从上电、引导程序到本程序把 PA1 设为输出（约 1 秒），
以及烧录的整个过程中，PA1 都是悬空的，蜂鸣器模块的输入会拾取串口和射频的干扰，发出“滴”声。下拉电阻让它在这段时间保持关闭。

低电平触发的模块（模块上的三极管为 PNP）需要把 `main.rs` 中的 `OFF_DUTY` 改为 255，否则不播放时蜂鸣器会一直通电；
这种模块的 10kΩ 电阻要改接在 PA1 和模块的 VCC 之间（上拉）。

## 舵机改装（9g 舵机，如 SG90）

普通舵机内部有一个和输出轴联动的电位器，用来反馈当前角度；输出齿轮上还有限位凸起，最多只能转 180°。
改装的目标是：去掉机械限位，并让电位器“以为”自己永远停在中点。改装后：

- 脉宽 = 中点（约 1.5ms）：停止；
- 脉宽比中点短或长：分别向两个方向连续旋转，偏离越多越快，偏离一两百微秒后就接近全速。

**只拆掉电位器是不行的**：没有反馈，舵机会乱转或一直全速转。

### 第 0 步：先把电位器放到中点（拆开之前做）

把 `main.rs` 中的 `CALIBRATE` 改为 `true` 并烧录，接好未改装的舵机，按任意按钮上电。舵机会转到中间位置（1.5ms）
并停住，此时电位器正好在中点。断电，**之后不要再转动电位器的轴**。

### 方法 A：保留电位器（推荐）

1. 拧下舵机底部的 4 颗螺丝，取下上盖，记下齿轮的排列顺序后取出齿轮；
2. 找到最大的输出齿轮（顶部有花键、连接舵盘的那个），把它侧面或底部的**限位凸起**用斜口钳剪掉，再用小锉刀修平；
3. 输出齿轮底部有一个 D 形孔，套在电位器的轴上带动它转动。用小钻头或刻刀把这个孔**扩成圆孔**，
   让齿轮可以在电位器轴上空转、不再带动电位器；
4. 按原顺序装回齿轮和外壳。

### 方法 B：用两个电阻代替电位器

1. 完成方法 A 的第 1、2 步（拆开、剪掉限位凸起）；
2. 剪断或焊下电位器的 3 根引线，在原来两端引线之间串联两个 2.2kΩ 电阻（SG90 的电位器约 5kΩ），
   两个电阻的连接点接原来的中间引线；
3. 去掉电位器（或保留在原处不再使用），装回外壳。

方法 B 的停止点由两个电阻的误差决定，只能在程序里微调；方法 A 停止点更准。

### 第 5 步：校准停止点

保持 `CALIBRATE = true`，装好改装后的舵机上电：

- 舵机完全停住：校准完成；
- 仍然慢慢转动：调整 `NEUTRAL_US`（默认 1500），每次改 5～10，直到停住。往哪个方向改可以试一次看转速变快还是变慢。

校准完把 `CALIBRATE` 改回 `false` 再烧录。

## 可调整的参数（`main.rs` 开头）

| 常量 | 默认值 | 作用 |
| --- | --- | --- |
| `NEUTRAL_US` | 1500 | 舵机停转时的脉宽（µs），见上面的校准步骤 |
| `FULL_SPEED_US` | 500 | 脉宽偏离中点多少视为全速 |
| `SPEED_PERCENT` | 50 | 转速百分比，脉宽 = 中点 ± `FULL_SPEED_US` × `SPEED_PERCENT` / 100，默认即 1250µs / 1750µs。改装后的舵机在偏离一两百微秒时就接近全速，嫌快可以调到 20～30 |
| `CALIBRATE` | false | 为 true 时忽略按钮，一直输出停转脉冲，用于校准 |
| `OFF_DUTY` | 0 | 蜂鸣器静音时的电平，低电平触发的模块改为 255 |

**方向**：按钮 S1（PB11）开机时脉宽大于中点，按钮 S2（PB12）开机时小于中点。按常见舵机的约定分别是逆时针和顺时针，
但改装方式不同（例如方法 B 的电阻接法）可能使方向相反；如果反了，交换 `pulse_us` 中 `Left` 和 `Right` 的 `+` / `-`，
或者直接交换两个按钮的检测线。两个按钮同时按着开机时舵机不转。

## 工作原理

### 开机检测按钮

按钮同时是电源开关，所以程序开始运行时，被按住的那个按钮的检测线一定是高电平。程序启动后立即读取 PB11 和 PB12：
只有一个为高电平就确定方向，都为低电平（用下载器供电）或都为高电平则舵机不启动。

从按下按钮到舵机开始转、音乐开始响，需要等 SDK 完成启动和 Wi-Fi 初始化，大约 1 秒左右。

### 断电续播与 Flash 寿命

播放记录保存在 Flash 用户区的最后一个扇区（4KB）中。每条记录 2 字节（歌曲索引和它的反码），每首歌开始播放前
在扇区里往后追加一条；开机时找到最后一条有效记录，从它的下一首开始播放。

Flash 每个扇区只能擦写约 10 万次。如果每次都写同一个地址，SDK 每次都要擦除整个扇区，按每小时换歌 200 多次计算，
连续播放二十来天就会写坏。追加写入时目标位置还是 0xFF，SDK 只编程、不擦除，一个扇区能存 2048 条记录，
写满才擦除一次，相当于寿命延长 2000 倍，实际使用中不用担心磨损。

掉电保护：写到一半掉电的记录校验不通过，开机时会被跳过；只有在写满后擦除扇区的瞬间掉电才会丢失记录，
此时从第一首开始播放。

### 软件产生舵机脉冲

舵机需要每 20ms 一个 1～2ms 的高电平脉冲。W600 的硬件 PWM 一个周期只能分 256 级，50Hz 时一级约 78µs，
而改装后舵机的调速范围只在中点附近一两百微秒，用硬件 PWM 每个方向只有两三档速度，停止点也调不准。

因此舵机由一个最高优先级的线程驱动：每轮关中断，把 TX0 拉高，用 SysTick 计时忙等到指定脉宽（精度约 1µs），
再拉低、开中断，然后休眠 18ms。每 20ms 只关中断 1.25～1.75ms，蜂鸣器由硬件 PWM 发声，不受影响。

## 已知限制

- 舵机启动后 TX0 不再输出串口日志；需要看日志时用下载器供电（舵机不会启动）。
- 上电时芯片的引导程序会在 TX0 上输出几十毫秒的启动信息，舵机可能轻微抖一下。
- 每首歌开始前写 Flash 时 CPU 会暂停几毫秒，每 2048 首擦除扇区时暂停更久，舵机脉冲会短暂中断。
- 没有转速反馈，实际转速会随电池电压和负载变化。
- 只适用于 W600（SysTick 计时代码针对 Cortex-M3）。
